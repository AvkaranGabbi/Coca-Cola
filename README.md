Coca-Cola Website Clone

A modern and responsive Coca-Cola themed website built using React and Vite. The project focuses on creating a visually appealing user interface with smooth animations and an engaging user experience.

Features

* Responsive design
* Modern React components
* Fast development with Vite
* Smooth animations and transitions
* Clean and organized project structure

Technologies Used

* React
* Vite
* JavaScript
* HTML5
* CSS3

Installation

Clone the repository:

git clone https://github.com/AvkaranGabbi/Coca-Cola.git

Navigate to the project directory:

cd Coca-Cola

Install the dependencies:

npm install

Start the development server:

npm run dev

The application will start locally. Open the URL displayed in the terminal (typically http://localhost:5173) in your browser.

Build for Production

To create an optimized production build:

npm run build

To preview the production build locally:

npm run preview
